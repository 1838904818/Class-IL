# Manuscript and technical documentation, 1 September 2026

This directory contains the evidence-aligned manuscript and technical document
after the paired five-seed checkpoint-selection experiment.

- `OFRA_ETG_Manuscript_v2_9_Checkpoint_Selection_2026-09-01.docx` and `.pdf`:
  formal manuscript.
- `OFRA_ETG_Technical_Document_v2_9_2026-09-01.docx` and `.pdf`: detailed
  architecture, preprocessing, experiment, result, and evidence-boundary
  description.

The new paired result does not establish superiority for training-only
checkpoint calibration. Last-epoch selection remains the primary protocol.
The matching public-safe result package is under
`results/replayids-d2-checkpoint-selection-paired5/`.
