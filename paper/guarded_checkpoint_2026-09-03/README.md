# OFRA-ETG manuscript and technical document v3.0

This revision adds the verified five-seed recall/FPR-guarded checkpoint result
from DICC Job 426307 without replacing the registered last-epoch primary.
The manuscript preserves the earlier unconstrained checkpoint ablation as a
separate experiment and reports both operating trade-offs, uncertainty
intervals, and limitations.

The DOCX and PDF files were rendered and checked page by page. Presentation
scripts and speaker notes are intentionally excluded from this public release.
