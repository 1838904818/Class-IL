# Referenced-paper library

This directory indexes every paper cited in the supervisor-revision
manuscript dated 12 August 2026. Links point to DOI records, official
proceedings, or author-approved open-access records.

PDF files are not mirrored here unless repository redistribution is explicitly
permitted by the paper's licence. Free-to-read access is not automatically a
licence to republish a publisher PDF. This index therefore provides durable
official links for the complete cited set without creating a copyright risk.
